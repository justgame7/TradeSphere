Management rules

Entry: use the current market price (Price column) for both confirmed and unconfirmed setups.
Base stop-loss: use the Kijun-sen baseline, below entry for Long and above entry for Short.
Conservative stop-loss: use the opposite cloud boundary, below entry for Long and above entry for Short.
TP1: 2R from Entry using the cloud stop distance. TP2: 3R from Entry using the cloud stop distance. Kijun is used only for Stop 1.
Exit: close at stop-loss, take-profit, or the next confirmed signal in the opposite direction.
